# Comment un ordinateur apprend-il ?

Entraînez votre premier modèle de machine learning (un polynôme), en
implémentant trois fonctions.

## Se connecter aux machines

1. Sur la page de connexion, entrez le nom d'utilisateur
   `usergymnaseX` et le mot de passe `LausanneEPFLX`, où `X` est le
   numéro du poste. Ce numéro est indiqué sur l'étiquette du poste.
   Par exemple, sur le poste 4 : `usergymnase4` /
   `LausanneEPFL4`.
2. Une fois connecté, cliquez sur la première option du menu de
   gauche : la session se lance.

## Télécharger et ouvrir le TP

1. Dans Firefox, ouvrez
   [github.com/PierreQuinton/Journee-Gymnasiens](https://github.com/PierreQuinton/Journee-Gymnasiens).
2. Cliquez sur le bouton vert `<> Code` → **Download ZIP**.
3. Dans le dossier **Download**, faites un clic droit sur le fichier
   ZIP → **Extract here**.
4. Ouvrez VS Code, cliquez sur **Open Folder…**, allez dans
   **Download** et sélectionnez le dossier extrait
   (**Journee-Gymnasiens** ou **Journee-Gymnasiens-main** selon le
   nom du fichier ZIP).
5. Ouvrez le fichier `src/lab_run.py`. Si VS Code propose d'installer
   l'extension Python, cliquez sur **Install**, puis rouvrez le
   fichier. S'il demande de choisir un interpréteur Python, acceptez
   celui proposé.
6. Cliquez sur le bouton ▶ pour lancer le programme.

Si le bouton ▶ ne fonctionne pas, sélectionnez la configuration
**`Lab`** dans le panneau **Run and Debug**, puis appuyez sur **F5**.
