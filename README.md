# Comment un ordinateur apprend-il ?

Entraînez votre premier modèle de machine learning (un polynôme), en
implémentant trois fonctions.

## Démarrer

1. Bouton vert `<> Code` → **Download ZIP**, puis dézippez.
2. VS Code → **Fichier → Ouvrir le dossier…** → le dossier dézippé.
3. Sélectionnez la configuration **`Lab`** à côté du bouton ▶,
   puis appuyez sur **F5**.
